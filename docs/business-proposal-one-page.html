Project Summary

This proposal covers full execution of a web-based certificate management and PDF generation platform using the existing Node.js architecture (Express, PostgreSQL, TypeORM, Handlebars, Puppeteer, QR code). The objective is to deliver a production-ready workflow from certificate input to signed PDF output.

Scope and Deliverables

  • Backend API hardening for certificate data operations.
  • Admin portal completion for create/update/retrieval workflows.
  • Branded, multi-page certificate template finalization.
  • Automated PDF generation and file output management.
  • QR code generation with certificate route verification.
  • Database configuration, deployment runbook, and handover docs.

Timeline

  • Week 1: Discovery and requirements lock.
  • Week 2-3: Backend and admin flow implementation.
  • Week 4: PDF/QR integration and template QA.
  • Week 5: UAT, production deployment, and handover.
